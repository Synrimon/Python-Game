# Python-Game
A small 99 Nights in the Forest story fan-game I've been working on ever since I started learning python. At this point, I'm mainly cleaning up what I made when I first started because I learned more things along the way :)

You find yourself deep in the forest, so deep that you can't find your way out and strange things are happening. Meet the Pelt trader, explore the forest—or don't— and it's mysteries, and survive.

How to play:
  1) Visit Code HS: https://codehs.com/sandbox/maroonarmadillo5402/99nitf-fan-game

OR
  
  2) copy all the code from game.py in this repository into a online python interpreter and run it
